Methods

(async) WGanttchart(inp) → {Promise}

Description:

  • 產製甘特圖 PNG(以 vis-timeline 繪製,需網路載 CDN)

Source:
  • WGanttchart.mjs, line 85
Example
import fs from 'fs'
import WGanttchart from 'w-ganttchart'

let inp = {
    axisStart: '2026-01-01',
    axisEnd: '2027-01-01',
    rows: [
        { id: 'a', label: '需求訪談', start: '2026-01-01', end: '2026-04-01', cls: 'navy' },
        { id: 'b', label: '系統開發', start: '2026-03-01', end: '2026-10-01', cls: 'azure' },
        { id: 'c', label: '驗收交付', start: '2026-10-01', end: '2027-01-01', cls: 'sky' },
    ],
}

let buf = await WGanttchart(inp)
fs.writeFileSync('gantt.png', buf)
// => 產出 gantt.png
Parameters:
Name Type Description
inp Object

輸入正規化甘特數據物件,格式 { axisStart, axisEnd, rows }

Properties
Name Type Description
axisStart String

輸入時間軸起始日字串,格式 'YYYY-MM-DD'
axisEnd String

輸入時間軸結束日字串,格式 'YYYY-MM-DD',須晚於 axisStart
rows Array

輸入橫條陣列,依序由上而下,每項為 { id, label, start, end, cls? };id 為唯一鍵(不可重複),label 為左側列標籤(以純文字呈現),start、end 為橫條起迄日('YYYY-MM-DD',end 不可早於 start),cls 為色票鍵(navy、azure、sky,未給或查無視為 azure)
Returns:

回傳 Promise,resolve 回傳 PNG 圖之 Buffer,reject 回傳錯誤訊息;輸入不合或繪圖庫(jsDelivr)載入失敗皆 reject

Promise
